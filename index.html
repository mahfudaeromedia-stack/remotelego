Program & Pengaturan

Simpan program untuk penggunaan berulang, tanpa akun dan tanpa backend.
Dukungan protokol: LEGO Wireless Protocol (BLE UUID 1623/1624); cocok untuk banyak hub Technic CONTROL+ empat-port. Kompatibilitas model tertentu dan port motor harus diuji dengan hardware asli.
Perangkat: Chrome/Edge yang mendukung Web Bluetooth, halaman HTTPS (disarankan Netlify). Browser iPhone/iPad tertentu tidak mendukung Web Bluetooth. Pastikan hub tidak sedang terhubung ke aplikasi LEGO CONTROL+ lain.
